- 后端工程师，专注 **LLM Agent 基础设施** —— 流式引擎、可观测性、MCP 工具链、终端体验
- 作者 of **[pulse](https://github.com/Luo-root/pulse)**：Go 生态的流式 Agent 引擎，`pulse-tui` 与 `PRism` 都构建在它之上 —— 一个引擎，长出一片生态
